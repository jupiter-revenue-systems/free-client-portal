# The Portal That Answers "Where Are We At?"

A live progress page for each client that shows where things are, what's next, what you need from them and their files. Fewer check-in emails, calmer clients.

## Who it's for

Coaches, consultants, agencies and service providers whose clients keep asking for updates, even when the project is on time.

## What's inside

- `GUIDE.md`: the full guide with every prompt.
- `templates/progress-page.md`: the 5-block progress page, ready to fill in.
- `templates/update-prompt.md`: the prompt that updates the page from 2 rough lines of notes.

## How to use it

1. Download this repo as a zip and unzip it.
2. Pick one client whose project is running now. Write rough notes on what's done, what's next and what you need from them.
3. Open Claude or ChatGPT, drag in this folder, and paste the first prompt from `GUIDE.md` with your notes.
4. Paste the finished page into a doc and share it view-only with the client.
5. When the work moves, use `templates/update-prompt.md` to refresh the page.
6. Put the page link under your name in every email to that client.

## What it doesn't do

- It's a shared doc, not a portal. No login, no brand, and each page is made by hand.
- It doesn't update itself.
- It only answers "where are we at?" It doesn't handle onboarding, payments or guides.
